场地格子材质 · 怎么替换

这个目录里的 PNG 就是决斗界面场地格子的皮。用同名文件覆盖即可。
尺寸不必严格照下面写（会被拉伸到格子的实际像素大小，格子大小随窗口变），
但比例要大致对：

  zone_monster.png  64x96   怪兽区空槽（额外怪兽区共用）
  zone_spell.png    64x96   魔法陷阱区空槽
  zone_field.png    64x96   场地区空槽
  zone_pile.png     64x72   牌堆槽：卡组 / 额外 / 墓地 / 除外
  mat.png           16x16   牌垫底，会被【平铺】而不是拉伸，四边要能接上

几点：

- PNG 的 alpha 有效。现在的空槽就是半透明的（让牌垫透出来）；换成不透明的也能用，
  只是空槽会看起来像「这个格子已经有卡了」。
- 牌堆槽（zone_pile）上面还会压一层 31% 的堆色（除外是灰的、卡组是蓝的…），
  用来区分是哪一堆，所以底纹别画得太满。
- 删掉某个文件不会崩，也不会退回色块：原版会画它自己的紫黑格子，
  那就是「这张还没画」的信号。id 不在清单里才会退回画色块。
- 清单的权威定义在代码里（cn.xm1221.ygomc.common.client.FieldTextureSpec）。
  要改名或加一种格子，改那边；只改这里的文件名，界面会认不出来。
